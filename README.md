# 🎧 Spotify-Style Page  

A **login page inspired by Spotify’s design**, built with **pure HTML and CSS**.  
This project focuses on **modern UI styling, layout structure**, and **basic responsiveness**, recreating a clean and elegant interface.  

---

## 💡 Technologies Used  

| Technology | Description |
|-------------|-------------|
| <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/html5/html5-original.svg" width="30px"> **HTML5** |  Page structure and semantic layout |
| <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/css3/css3-original.svg" width="30px"> **CSS3** |  Styling, layout, and visual effects |
| <img src="https://raw.githubusercontent.com/ionic-team/ionicons/main/docs/assets/logo.svg" width="30px"> **Ionicons** |  Modern icons used in input fields |

---

## 🖥️ Features & Design  
- Centered, responsive layout  
- Dark color palette inspired by **Spotify**  
- Smooth **hover** and **shadow** effects  
- Input fields with icons and soft borders  
- Gradient background with subtle lighting  

---

## 🚀 Purpose  
This project was developed to **improve front-end skills**, exploring techniques like:  
- CSS gradients and shadows  
- Button transitions and hover effects  
- Flexible and modern form layouts
